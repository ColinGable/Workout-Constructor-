# Workout Constructor

A desktop application for building and managing custom client workouts using a graphical interface.

## Features

- Enter and manage individual client workouts
- Select exercises by muscle group
- Choose exercises from a stored exercise database
- Set reps and sets for each exercise
- Add exercises to a workout
- Remove exercises from an existing workout
- Display the current workout in a table
- Save workouts to client-specific CSV files
- Archive completed workouts
- PyQt6 graphical interface

## Technologies

- Python
- PyQt6
- pandas
- CSV File Handling
- Object-Oriented Programming
- Git / GitHub

## How It Works

The user enters a client name and then selects a muscle group, exercise, number of reps, and number of sets. Exercises can be added to the client's workout and are displayed in a table. Workout information is saved to a client-specific CSV file so it can be accessed again later. Exercises can also be removed, and completed workouts can be archived for future reference.
